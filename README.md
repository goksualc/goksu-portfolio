# Göksu Alçınkaya – Portfolio

Personal portfolio website with an editorial design aesthetic.

**Live Site:** [goksualcinkaya.vercel.app](https://goksualcinkaya.vercel.app)

---

## About

This portfolio takes an editorial, magazine-inspired approach — clean typography, structured layouts, and a cream/red color palette. It highlights my work in Web3, developer relations, and software engineering.

Sections:
- **Home** – Introduction and featured work
- **Projects** – Selected projects in blockchain, security, and creative coding
- **Experiences** – Professional highlights, hackathons, and community events
- **Education** – Academic background
- **Blog** – Personal and technical writings

---

## Tech Stack

- **Framework:** Next.js 15 (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Typography:** Cormorant Garamond (display), Inter (body)
- **Deployment:** Vercel

---

## Getting Started

```bash
git clone https://github.com/goksualc/goksu-portfolio.git
cd goksu-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## Folder Structure

```
/app            → Routes and pages (App Router)
/components     → Shared UI components (Navbar, PageTransition, etc.)
/public         → Static assets
```
